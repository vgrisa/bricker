# Identidade Bricker

- `logo-primary.png`: versão principal fiel à arte aprovada, para fundos claros.
- `logo-on-dark.png`: versão clara para fundos verdes ou escuros.
- `logo-primary.svg`: versão vetorial simplificada para impressão e redimensionamento.
- `symbol.png` e `symbol.svg`: símbolo isolado.
- `icon-512.png`: ícone de alta resolução.
- `favicon.ico`, `favicon-32.png` e `apple-touch-icon.png`: ícones do navegador e dispositivos.

## Cores

- Verde principal: `#24523E`
- Verde profundo: `#183C2D`
- Terracota: `#C8643E`

Mantenha espaço livre ao redor da marca e não altere suas proporções ou cores.
